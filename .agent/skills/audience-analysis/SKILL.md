# Audience Analysis

## Procedure
1. Define a bounded sample: items, comment count, sorting mode, collection date, and exclusion rules.
2. Record that platform sorting and moderation may bias the sample.
3. Code themes using a transparent codebook; distinguish praise, criticism, questions, disagreement, spam, and off-topic content where relevant.
4. Preserve anonymized examples only when necessary; avoid collecting unnecessary personal data or amplifying private individuals.
5. Report counts and denominators. Separate observed comments from inferred audience-wide views.
6. Do not infer commenter demographics, beliefs, mental states, or representativeness without appropriate direct evidence.
7. Do not claim that the creator persuaded an audience merely because comments express agreement.
8. Include sampling, language, moderation, and platform limitations.

## Output
Sample protocol, codebook, theme counts, selected anonymized examples if useful, limitations, and reproducible notes.

## Failure conditions
Do not present a convenience sample as representative of all viewers or followers.
