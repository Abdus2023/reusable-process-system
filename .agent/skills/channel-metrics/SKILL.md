# Channel Metrics

## Procedure
1. Define the measurement date and exact platform/account.
2. Record only visible or explicitly sourced values: subscribers/followers, total views, uploads, recent posting cadence, views per sampled item, and visible engagement counts.
3. Attach source URL or observation method to every value.
4. Record metric observation date and whether the value is direct, estimated by a named service, or unavailable.
5. Separate:
   - reach: subscriber/follower base and accumulated views;
   - activity: posting frequency and recency;
   - performance: recent item-level views and engagement.
6. Use a declared and repeatable sample window. Report sample size and exclusions.
7. Do not infer audience geography, demographics, trustworthiness, content quality, or persuasion from aggregate metrics.
8. If ranking is required, publish formula, weights, date, missing-data treatment, and sensitivity limitations. Prefer category directory when ranking is not defensible.

## Output
Metric snapshot, sample definition, source log, missing-data report, and optional reproducible ranking.

## Failure conditions
Never invent unavailable metrics, mix dates without labels, or compare incomparable platform metrics as if equivalent.
