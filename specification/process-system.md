# Reusable Process Engineering System

## Purpose

The system provides reusable machinery for turning process knowledge into governed, testable, evidentiary, releasable process artifacts.

## Scope

The system covers:

- process discovery and extraction
- process specification
- process decomposition
- skill and tool contracts
- orchestration
- evidence production
- execution evidence
- verification
- conformance
- release

## Non-scope

The system does not make GPJK the universal process language. GPJK is one supported specification/integration boundary.

The system does not inherit Kerno-specific policy, repository assumptions, or runtime semantics merely because those originated in the extraction source.

## Trust principle

No claim is verified without sufficient scope, snapshot, and evidence.

## Architecture

Core process engineering is representation-independent where practical. Representation-specific semantics belong behind explicit integrations.

## Extraction status

This specification is the foundation for the standalone extraction from Kerno. It is not evidence that the eventual implementation has passed its verification gates.
